# Sistema Bancário em Java

## Sobre o projeto

Esse é meu primeiro projeto de lógica de programação em Java, desenvolvido a partir dos conhecimentos que estou adquirindo no curso de Java do Nélio Alves, na Udemy.

A ideia foi colocar em prática o que aprendi nos três primeiros módulos do curso: estrutura sequencial, estrutura condicional e estrutura repetitiva.

## Como funciona?

O projeto consiste em um sistema bancário simples, executado pelo console, com quatro opções disponíveis no menu:

- **Consultar saldo:** verificar o saldo disponível na conta.
- **Depositar:** adicionar um valor ao saldo, desde que seja válido.
- **Sacar:** retirar um valor da conta, verificando se ele é válido e se existe saldo suficiente.
- **Sair:** encerrar o sistema por meio da opção zero.

## O que foi utilizado?

Durante o desenvolvimento, coloquei em prática alguns dos conceitos estudados no curso:

- **Estrutura sequencial:** declaração de variáveis, tipos de dados, entrada e saída de dados.
- **Estrutura condicional:** utilização de `if-else` para verificar condições e validar operações.
- **`switch-case`:** organização das opções disponíveis no menu do sistema.
- **Estrutura repetitiva:** utilização do `while` para manter o sistema funcionando e permitir que o usuário realize mais de uma operação antes de sair.

## Objetivo

O objetivo desse projeto foi praticar os conteúdos que venho estudando e começar a desenvolver meus próprios programas em Java.

Esse é meu primeiro passo na criação de projetos próprios, e pretendo continuar evoluindo e colocando em prática os próximos conhecimentos que adquirir durante meus estudos.
